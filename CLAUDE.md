# my-designs

**This repository is PUBLIC.** Anything committed here becomes visible to anyone
the instant it is pushed, and is published as a website at
https://nikunjvermaa.github.io/my-designs/ via GitHub Pages on `main`.
Search engines can index it. Treat every commit as a publication.

## Purpose

A display shelf for design previews, so Nikunj can look at a design on his phone.
Deliberately kept near-empty. This is not a working repository.

## Hard rules

- **Never copy anything here from `my-company`** (the private repo) unless
  Nikunj explicitly asks for that specific file. When you do, state clearly in
  your reply that the file is now public.
- **Never commit credentials or internal material** — no client names, pricing,
  contracts, or unreleased work unless he explicitly says to publish it.
- If a request would expose something and it's ambiguous, ask first. The cost of
  asking is a message; the cost of guessing wrong is permanent.

## Layout

Design files at the root, or in dated subfolders. `README.md` is what GitHub
Pages renders as the site's index page.
